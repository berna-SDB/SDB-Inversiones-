| Retención | Base de cálculo | Tasa |

| Fondo de Reparo | Monto bruto factura | 10% |

## Gotchas encontrados

- `record.copy` de PO preserva el ítem original — si el ítem original no es el deseado, forzar con `setCurrentSublistValue('item', ...)`.
- Ítem 5015 es Inventory → requiere Asset/COGS/Income **distintos** (NetSuite bloquea con "You may not use duplicate accounts").
- Cambiar costing method de un ítem con histórico → error "Inventory Revaluation is no longer the first transaction in the item's history". No se puede cambiar, hay que borrar histórico o aceptar.
- Vendor Payments USD transformados de bill fallan con "Debe introducir al menos una línea de artículo" si no se setea `currency` + `exchangerate` explícito y se commitea el sublist `apply`.
- Git Bash en Windows destruye paths que empiezan con `/` al pasarlos al CLI de suitecloud. Fix: prefix con `MSYS_NO_PATHCONV=1`.
